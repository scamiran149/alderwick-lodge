# Alderwick Lodge

[Visit Alderwick Lodge](https://scamiran149.github.io/alderwick-lodge/)

A fictional lakeside retreat in Washington’s North Cascades. The brochure unfolds across eleven scenes. Start at the shore, pick up a key at reception, and keep reading past the end of the printed guide.

The site uses plain HTML, CSS, and JavaScript. Images and fonts are served locally. Sound is optional and synthesized in the browser. The visitor guide has a still-scene control, and the story also honors the device’s reduced-motion setting. The interactive details use in-memory state for the current visit. “Back to daylight” resets the story.

## Local preview

Run `python3 -m http.server 8000` in the repository and open `http://localhost:8000`. GitHub Pages serves the root of `main`.

## Art and type

The ten images in [assets](assets/) were created with the built-in OpenAI ImageGen tool. The second exposure uses the original east dock photograph as its edit target. Lato and Noto Serif Display are distributed under the SIL Open Font License. Their license files are included in [assets/fonts](assets/fonts/).
