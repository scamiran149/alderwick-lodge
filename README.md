# Alderwick Lodge

[Visit Alderwick Lodge](https://scamiran149.github.io/alderwick-lodge/)

A fictional lakeside retreat in Washington’s North Cascades. Start at the shore and scroll through the lodge grounds, the ranger’s notes, and the night register. The last stretch is an interactive horror scene.

The site uses plain HTML, CSS, and JavaScript. Images and fonts are served locally. Sound is optional and synthesized in the browser. The ending honors reduced-motion settings, and the visitor guide includes a still-scene control.

## Local preview

Run `python3 -m http.server 8000` in the repository and open `http://localhost:8000`. GitHub Pages serves the root of `main`.

## Art and type

The six original images in [assets](assets/) were created with OpenAI ImageGen. Lato and Noto Serif Display are distributed under the SIL Open Font License. Their license files are included in [assets/fonts](assets/fonts/).
